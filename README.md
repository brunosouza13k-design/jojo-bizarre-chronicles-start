# JoJo Bizarre Chronicles

Crie uma Tela de Início (Main Menu) espetacular e responsiva para o nosso jogo de RPG 2D de JoJo's Bizarre Adventure.



1. VISUAL E ESTILO:

- O fundo deve ser escuro e misterioso, com um gradiente roxo e dourado profundo (as cores clássicas de JoJo).

- Adicione elementos flutuantes sutis em CSS no fundo (como as famosas onomatopéias "Menacing/Gogogo" do anime flutuando suavemente para cima).

- O título do jogo deve ser grande, centralizado e com uma fonte estilizada em dourado tridimensional com bordas pretas fortes, escrito: "JOJO'S BIZARRE ADVENTURE: THE CHRONICLES".



2. MENU INTERATIVO:

- Crie três botões centralizados e empilhados verticalmente no meio da tela:

  - Botão 1: "NOVO JOGO" (Com um efeito de brilho ou destaque ao passar o dedo/mouse).

  - Botão 2: "SELECIONAR PARTE" (Um botão para escolher qual mistério jogar no futuro).

  - Botão 3: "CRÉDITOS & OPÇÕES".

- Os botões devem ter cantos arredondados, bordas douradas e um efeito sonoro de "clique" ou clique visual imediato.



3. FUNCIONALIDADE DE TRANSIÇÃO:

- Ao clicar em "NOVO JOGO", faça a tela atual desaparecer com um efeito elegante de "fade-out" (esmaecer) preto para nos preparar para entrar no mapa do RPG.

- Por enquanto, mostre uma tela preta provisória escrita "Carregando Novo Universo..." para que possamos construir o mapa n

a próxima etapa.
